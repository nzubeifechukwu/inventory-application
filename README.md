# Book Inventory

Book inventory is an inventory management app for an imaginary bookstore. Built with Express (NodeJS), the app lets you perform basic CRUD (Create, Read, Update, Delete) like add books, view books, edit books, and delete books.

See the [live demo](https://inventory-application-suf0.onrender.com/).

## Tools, languages and frameworks

- **ExpressJS (NodeJS)**
- **PostgreSQL (SQL)**
- **Embedded JavaScript (EJS)**
- **node-postgres (pg)**, to interface with the Postgres database
- **express-validator**, to validate and sanitize HTML inputs
